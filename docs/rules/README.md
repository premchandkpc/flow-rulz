# Rules documentation

This area contains authoring standards and lifecycle expectations. The existing [rules reference](../rules.md) describes the current rule JSON shape, predicates and operators; the [ruleset guide](../ruleset.md) documents immutable revisions and Service assignments.

## Files
- [Rule authoring standard](rule-authoring-standard.md): structure, determinism, validation, safety and review.
- [Rule lifecycle](rule-lifecycle.md): draft, validate, publish, activate and retire.

Ruleset activation, contract validation, runtime evaluation, and effect delivery are separate stages. Do not describe a stage as guaranteed unless implementation and tests prove it. Record unsupported operators or semantics as limitations.
